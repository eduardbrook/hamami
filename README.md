# נוכחות וסטטיסטיקה

אתר סטטי לצפייה בלבד: דוחות נוכחות (שבועי, חודשי, כל התקופה), משחקים וסטטיסטיקה, ובדיקות גופניות.

- `index.html` הוא הדף עצמו. הוא לא משתנה בין עדכונים.
- `data.json` הוא צילום מצב של הנתונים. רק הקובץ הזה מתעדכן.
- האתר מתפרסם דרך GitHub Pages מהענף הראשי.

האתר ציבורי: כל מי שיש לו את הכתובת רואה את הנתונים. הדף מסומן `noindex` כדי שמנועי חיפוש לא יאנדקסו אותו.
